Privacy policy

WoW PvP Editor · last updated: 2026-11-01

WoW PvP Editor is a personal tool that runs only on its owner's own computer. It is used by its owner only.

What data it uses

  • YouTube (Google): permission to upload videos to the owner's own channel and to read that channel's basic information (channel name and the status of the uploaded videos).
  • Instagram (Meta): permission to publish videos to the owner's own professional account.
  • Facebook (Meta): permission to publish videos (Reels) to the owner's own Facebook Page.
  • TikTok: permission to send videos to the owner's own TikTok inbox as drafts, which the owner finishes and posts in the TikTok app.

What it does NOT do

  • It does not access, collect or store data of any other person.
  • It does not sell, share or transfer any data to third parties.
  • It does not use the data for advertising or analytics.

Where the data is kept

Access permissions are stored only on the owner's computer, encrypted with the operating system's protection (Windows DPAPI). Nothing is stored on any server run by this tool.

How to revoke access

The owner can revoke access at any time: Google at myaccount.google.com/permissions, Instagram and Facebook (Meta) in the account's «Apps and websites» settings, and TikTok in the app's «Security» settings. Deleting the local files removes all stored permissions.

Google API Services

WoW PvP Editor's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
